# Portfolio

Personal portfolio website built with [React 19](https://react.dev/), [Vite](https://vite.dev/), and [Tailwind CSS v4](https://tailwindcss.com/).

## Getting Started

First, install dependencies:

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

## Scripts

- `pnpm dev` - Start the Vite development server with HMR.
- `pnpm build` - Type-check with TypeScript and build for production.
- `pnpm preview` - Locally preview the production build.
- `pnpm lint` - Run ESLint.
